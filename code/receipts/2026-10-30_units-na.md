# Receipt: units stay n/a; scale of the stored values against the release's PSD tables

**Claim**: no file, table or script of the release states a unit, scale or gain for the recordings, so `units` stays
n/a (channels.tsv as on `origin/main`; headers 'unscaled'). The README keeps the scale evidence as ratios: the
per-participant median band-power ratio (stored / release PSD table) is 0.80-2.03 for the interictal runs (all six bands
within 0.5-2 for 28 of 29 participants) and 0.0008-4.5 for the ictal runs (22 of 29; not P004, P007, P013, P014, P018,
P020, P025).

**PR**: nemarDatasets/nm000413#3, head `606f0eff2c7d985479bb5ed5c323d1ab15f268fa` (the receipt commit only replaces the
2026-10-22 units-volts receipt with this one). It replaces that receipt because the V claim rested on inference (the
notebook reads the EDFs with MNE, plus the scale match below), not on a source that states the unit.

## Method
- Script: `2026-10-30_units-na.py <nm000413 root> <git clone> <PR head> <dir with the release sourcedata>` (MNE 1.13.2,
  numpy 2.5.4, scipy 1.18.1, h5py 3.16.0, pandas, openpyxl), run on Slurm.
- Unit statements: a name or text counts when it matches `units?|volt|µV|uV|mV|nV|gains?|calib|physical|dimension|
  scale(d)|scaling` (case-insensitive, word-bounded where needed). MAT files: variable names, MATLAB classes and struct
  fields (`scipy.io.whosmat`), and the names and strings of every variable with at most 100,000 elements (the signal
  matrices `eeg_data` / `data` are not read); spreadsheets and result tables: every text cell; scripts: notebook cell
  sources and text outputs, `.m` files line by line; Zenodo record: its metadata values.
- Units at the head: channels.tsv rows per (type, units) and byte comparison with `origin/main`; the unit field of every
  `Ch<n>=` record of the 190 headers.
- Ratios, as in the notebook: Welch `welch(x, fs, nperseg=fs)` on the whole stored run (MNE `read_raw_brainvision`,
  header unit 'unscaled' with resolution 1, so the stored values unscaled), the same mains-bin replacement and the same
  six bands; the notebook's 999 Hz low-pass, notch filter and `sz_S..sz_T` crop are not applied, because the crop limits
  are not released. Runs are paired with the table of the same name in the same state folder (`<stem>.xlsx`,
  `<stem>_psd.xlsx` or `new_<stem>.xlsx`, case-insensitive); channels are matched by name. Ratio = stored / table band
  power per channel; per participant, the median per band over all paired runs, counted as close when within [0.5, 2].
